## 交付门槛

- 每项实现前跑 impact；索引过期/UNKNOWN 时补全证据，不能将空 caller 当作低风险。需要重建源码索引时另按仓库规则办理，不能静默刷新用户索引。
- 每项提交保存输入/输出一致性、错误路径和峰值内存证据；保留 cancellation、spill、native shutdown、embeddings 与发布原子性。
- 最终至少 3 次独立冷构建，每次完整 wall ≤180 秒。报告中位数和范围；缓存强制重建、无变更运行另列，不能替代冷构建。
- 禁止通过关闭 FTS、减少资源/语言范围、跳过输入核验或截断内容达标。若仍未达标，地图保持 open，并将新证据转为明确任务。
