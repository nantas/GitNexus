# 降低输入核验 I/O 成本


已于 2026-10-26 按现有候选决策收口：小缓冲、持续补位、目录限流与 ignore 缓存均沿用已有否决/收益不足结论，不采纳；两次完整哈希与输入变更回归保留。 完整证据见[现有验证项收口与候选否决](resolution.md#现有验证项收口与候选否决2026-10-26)。下文为历史调查顺序；关闭本票不表示 180 秒目标已达成。

## Question

能否在完整内容哈希、枚举错误传播和发布前重新核验都不变的条件下，减少重复目录遍历与小文件 I/O 调度？

## Evidence and next experiment

- **最新完整验证**：[持续补位完整构建与压力归因](resolution.md#持续补位完整构建与压力归因2026-10-26)。A/B 为 526.995/442.504 秒，但最终哈希只快 0.339 秒，CPU 142.367/143.054 秒，最终 snapshot 57.046/60.343 秒。完整事实一致；单对峰值 12.075/11.781 GiB，不能推出稳定改善。暂不采纳，候选降为低优先级；下一主项转至 [FTS 前内容导入与系统压力](fts.md)，不继续扩大调度微优化。

- **当前结果**：[批次屏障与持续补位验证](resolution.md#哈希批次屏障与持续补位验证2026-10-26)。已确认约 67.6% 的逻辑槽位占用；同为 16 并发持续补位在三对只读样本中均降低哈希耗时，中位数 17.608→16.310 秒，CPU 约降 19.3%。完整上下文/慢读取收益仍未验证，保留候选，下一步做当前输入的完整构建与峰值验收。

- 前序诊断：[操作级等待诊断与新输入快照](resolution.md#操作级等待诊断与新输入快照2026-10-26)。目标 HEAD 已变化，当前只读输入为 164,026 文件，不与旧完整基线直接比较。无 DB 的相同探针复现 157.324/35.976 秒；主要差异在 read 回调和枚举等待，SHA 约 2.4 秒。32 请求目录限流未显示收益。下一步检验固定 16 文件批次的尾部等待，再试同并发上限的持续补位，保持排序与失败 settle 语义。

- 历史决议（旧输入）：[无采样器三对验证与存储等待转向](resolution.md#无采样器三对验证与存储等待转向2026-10-26)。最终哈希 CPU 中位数下降 57.3%，但完整 wall 中位数 A/B 为 441.236/447.557 秒，两对变慢、峰值存在反例，暂不采纳缓冲改动。下一步对 readdir/stat/open/read/close 做分段等待诊断，分开外置 HFS+ 源盘与内置 APFS 索引盘。

- 历史候选：[GC 归因与小文件缓冲候选](resolution.md#gc-归因与小文件缓冲候选2026-10-26)。独立完整对照中，按 stat.size 限制 ReadStream 缓冲使最终哈希 CPU/major GC 显著下降，但只有一对带采样样本且峰值升高；先做无采样器至少三对交替 A/B，再决定采纳。先补极小文件增长、短读和读取失败回归，不重写读取实现。

- 2026-10-26 [完整构建分段](resolution.md#完整构建内的核验分段2026-10-26)把当前主调查收窄到 snapshot 临时分配/GC，该阶段已由 FTS 票完成，后续重复验证由本票承接；不同时运行实验。历史 FileHandle/hash 替换无稳定收益的结论仍有效；缓冲复用仅在新增分配证据支持后重试。

- 续查决议见[重复测量条件决议](resolution.md#重复测量条件决议2026-10-23-续查)：下一候选收窄为单次 source glob 的重复 ignore 判断，暂不合并三种枚举。局部 WeakMap 实验清单一致，中位数仅省 1.097 秒；正式实现前须补否定规则、失败路径、峰值内存和完整 A/B。现阶段优先完成 FTS/发布前核验压力调查，不为小收益扩大共享 ignore 服务改动。

- 已测冷构建开始/发布核验 33.044 / 72.868 秒；热重建 139.765 / 51.711 秒；无变更核验 111.661 秒。
- 分别计时清单枚举、ignore/scope、metadata 探测、hash 读取；先确认真实冷读和缓存读差异。
- 依证据试验共享枚举结果、有界小文件读取或 I/O 调度；之前 FileHandle 直接替换没有稳定收益，不能据一次快样本复活方案。
- 不用 stat/mtime 代替内容哈希，不取消前后两次核验；保留新增/删除文件、控制文件变化、同路径替换、读取中修改和读取错误的检测。

## Acceptance

同一输入 receipt、哈希清单完全一致；输入一致性回归通过，A/B 完整 wall 有重复收益且峰值内存不恶化。失败或输入变化不得发布新索引。
